# RecursiveAI.OneRender.Fonts.Cjk

Noto Sans CJK for OneRender: Regular and Bold collections holding the Japanese, Korean, Simplified Chinese, Traditional Chinese and Hong Kong faces, embedded byte-for-byte.

Reference the package and it registers itself at start-up; text in Chinese, Japanese and Korean then falls back to these faces (Japanese by default). The files are the upstream release files, verified by SHA-256 against the manifest.
