# RecursiveAI.OneRender.Fonts.Emoji

Noto Color Emoji for OneRender: the upstream CBDT/CBLC color bitmap font (the build with an empty glyf table, which every TrueType reader accepts), embedded byte-for-byte.

Reference the package and it registers itself at start-up; emoji then draw from the color bitmap glyphs, in image and PDF output. The files are the upstream release files, verified by SHA-256 against the manifest.
