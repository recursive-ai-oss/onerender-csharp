# RecursiveAI.OneRender.Fonts.Noto.Arabic

Noto Arabic fonts for OneRender: the Noto Sans Arabic release files, embedded byte-for-byte.

Reference the package and it registers itself at start-up; text in this script then falls back to these faces. Call `Register()` on the package class to register it by hand. The files are the upstream release files, verified by SHA-256 against the manifest.
